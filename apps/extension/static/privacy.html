Politique de confidentialité de Neptune

Version du 25 juillet 2026 — Neptune 1.5.

Neptune minimise les données transmises. Les préférences, l’historique, le journal des missions, les modèles locaux sélectionnés et les clés fournisseur restent dans le profil Chrome de l’utilisateur, sauf lorsqu’une requête doit être envoyée au fournisseur cloud choisi.

Données conservées localement

  • prénom d’usage, voix choisie, niveau de contrôle et activation vocale ;
  • historique conversationnel et journal des missions ;
  • configuration du fournisseur d’intelligence ;
  • sélection et cache du modèle d’intelligence local ;
  • clés API chiffrées localement avec AES-GCM.

Voix françaises intégrées

Les deux modèles vocaux français proposés pendant l’accueil — une voix féminine et une voix masculine — ainsi que Piper et les fichiers WebAssembly nécessaires sont inclus dans le package de l’extension. Neptune ne télécharge pas une voix lors du premier lancement et n’utilise pas la voix Windows par défaut pour ses réponses.

Le texte est transformé en audio directement dans l’extension, dans un Web Worker séparé. Neptune n’envoie ni le texte à prononcer ni l’audio généré à un service distant de synthèse vocale.

Intelligence locale

Neptune Équilibré est sélectionné comme moteur local par défaut. Lors de sa première préparation, les poids du modèle WebLLM sont téléchargés depuis leur emplacement de distribution puis conservés dans le cache local IndexedDB de Chrome. Ces fichiers contiennent le modèle et son runtime, pas les conversations de l’utilisateur.

Lorsque l’intelligence intégrée de Chrome ou un modèle WebLLM local est utilisé, les instructions, le contexte utile de la page et les réponses sont traités sur l’ordinateur.

Activation vocale

Après autorisation du microphone, Neptune peut écouter les expressions « Neptune » et « OK Neptune » lorsque Chrome reste ouvert. Un document d’extension hors écran maintient cette écoute. Les transcriptions nécessaires à la commande sont traitées par les mécanismes de reconnaissance vocale disponibles dans Chrome.

Données transmises

Lorsqu’un fournisseur cloud est choisi dans les paramètres avancés, les messages nécessaires à la réponse ou à la planification sont envoyés directement à ce fournisseur selon ses propres conditions. Neptune n’envoie jamais une clé API à un autre fournisseur que celui configuré.

Pour accomplir une mission navigateur, Neptune lit uniquement la page définie comme espace de travail et ne fournit au moteur d’intelligence que le contexte nécessaire à l’objectif demandé.

Permissions navigateur

L’accès aux sites est demandé avant la première mission nécessitant de lire ou manipuler une page. Selon la décision de l’utilisateur, Neptune peut travailler dans la page actuelle, un nouvel onglet ou une nouvelle fenêtre. L’extension ne contourne pas les protections de sécurité des plateformes.

Actions sensibles

Neptune refuse d’automatiser les paiements, achats, suppressions de compte, mots de passe, codes secrets, signatures, virements et contournements de CAPTCHA. Les communications externes exigent une autorisation explicite.

Suppression des données

L’utilisateur peut effacer la conversation et le journal depuis les réglages. Le cache du modèle local peut être supprimé en effaçant les données de stockage de l’extension dans Chrome. La désinstallation supprime les données associées au profil Chrome, sous réserve des mécanismes de sauvegarde propres au navigateur.
