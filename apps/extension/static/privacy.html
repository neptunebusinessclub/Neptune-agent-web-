Politique de confidentialité de Neptune

Version du 30 juillet 2026 — Neptune 1.8 Hermes Integrated.

Hermes Agent est le cerveau local géré par défaut. Neptune l’installe et le configure automatiquement sur l’ordinateur. Aucune clé API commerciale, URL de serveur ou configuration CORS n’est demandée à l’utilisateur.

Données conservées localement

  • prénom d’usage, voix choisie, niveau de contrôle et activation vocale ;
  • historique conversationnel et journal des missions dans le profil Chrome ;
  • mission, checkpoint et état d’arrêt courant dans le stockage de session Chrome ;
  • identifiants techniques de continuité de session Hermes ;
  • sélection et cache éventuel des moteurs de secours ;
  • copies privées des fichiers vocaux embarqués dans OPFS ;
  • runtime Hermes, modèle local, journaux techniques et configuration dans le compte Windows courant.

Voix françaises embarquées

La voix féminine Siwis et la voix masculine UPMC/Pierre, ainsi que Piper, le phonétiseur et les fichiers WebAssembly nécessaires, sont incluses dans le package de l’extension.

Au premier usage, Neptune copie ces ressources vers le stockage privé OPFS de Chrome et vérifie leur écriture avant la synthèse.

Le texte est transformé en audio dans un Web Worker de l’extension. Neptune n’envoie ni le texte à prononcer ni l’audio généré à un service distant de synthèse vocale. La voix Windows n’est pas utilisée dans le parcours normal.

Hermes Agent intégré

NeptuneSetup.exe installe automatiquement Hermes Agent, llama.cpp et le modèle Qwen3-4B Q4_K_M dans %LOCALAPPDATA%\Neptune\Hermes.

Hermes et le serveur de modèle écoutent uniquement sur l’interface locale 127.0.0.1. Ils ne sont pas exposés au réseau local ni à Internet par Neptune.

Une clé aléatoire est générée localement. Elle est protégée par les droits du compte Windows courant et transmise à l’extension uniquement par le host Native Messaging autorisé pour l’identifiant fixe de Neptune. Elle est conservée dans le stockage de session Chrome pendant l’utilisation, et non affichée dans l’interface.

Les messages, observations utiles de la page et réponses sont traités par Hermes sur l’ordinateur. Hermes peut utiliser sa mémoire, ses compétences et ses outils locaux selon la mission demandée. Les actions dans l’onglet Chrome restent exécutées par Neptune et soumises à ses validations.

Les réponses Hermes sont reçues en flux. Le bouton Arrêter ferme le flux et interrompt l’exécution en cours.

Téléchargements au premier lancement

L’installateur contacte les dépôts officiels de Nous Research, llama.cpp et Qwen/Hugging Face pour télécharger les composants nécessaires. Les archives llama.cpp et le modèle Qwen sont vérifiés par empreinte SHA-256 avant installation.

Après installation, l’usage courant du cerveau peut fonctionner localement. Les compétences Hermes qui réalisent volontairement une recherche web peuvent naturellement accéder aux sites nécessaires à la demande.

Moteurs de secours facultatifs

Un modèle navigateur local, Mammouth AI ou une API compatible OpenAI peut être choisi dans les paramètres avancés comme moteur de secours. Un fournisseur externe n’est utilisé qu’après cette sélection explicite ; ses messages et sa clé sont alors traités selon ses propres conditions.

Activation vocale

La permission microphone est demandée uniquement après une action explicite de l’utilisateur. Après autorisation, Neptune peut écouter les expressions « Neptune » et « OK Neptune » lorsque Chrome reste ouvert.

Si la permission est refusée ou fermée, l’accueil reste utilisable au clavier et propose de réessayer ultérieurement.

Permissions navigateur

L’accès aux sites est demandé avant la première mission nécessitant de lire ou manipuler une page. Neptune peut travailler dans la page actuelle, un nouvel onglet ou une nouvelle fenêtre selon la décision de l’utilisateur.

La permission nativeMessaging sert uniquement à communiquer avec le host local com.neptune.hermes, dont les commandes sont limitées à la vérification, au démarrage et à la réparation du runtime.

Les permissions http://127.0.0.1/* et http://localhost/* servent uniquement à joindre les composants locaux de Neptune.

Actions sensibles

Neptune refuse d’automatiser les paiements, achats, suppressions de compte, mots de passe, codes secrets, signatures, virements et contournements de CAPTCHA. Les communications externes exigent une autorisation explicite limitée à l’action concernée.

Suppression des données

L’utilisateur peut effacer la conversation et le journal depuis les réglages. Les fichiers du runtime et les mémoires Hermes peuvent être supprimés en désinstallant Neptune puis en supprimant le dossier %LOCALAPPDATA%\Neptune\Hermes.
