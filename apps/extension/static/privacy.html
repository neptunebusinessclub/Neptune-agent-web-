Politique de confidentialité de Neptune

Version du 30 juillet 2026 — Neptune 1.7 Hermes Brain.

Neptune minimise les données transmises. Le cerveau local reste le choix par défaut. Hermes Agent, Mammouth AI et les autres fournisseurs externes ne sont utilisés qu’après une configuration explicite dans les paramètres avancés.

Données conservées localement

  • prénom d’usage, voix choisie, niveau de contrôle et activation vocale ;
  • historique conversationnel et journal des missions ;
  • mission, checkpoint et état d’arrêt courant dans le stockage de session Chrome ;
  • configuration du fournisseur d’intelligence ;
  • identifiants techniques de continuité de session Hermes, sans contenu de conversation ;
  • sélection et cache du modèle d’intelligence local ;
  • copies privées des fichiers vocaux embarqués dans OPFS ;
  • clés API chiffrées localement avec AES-GCM.

Voix françaises embarquées

La voix féminine Siwis et la voix masculine UPMC/Pierre, ainsi que Piper, le phonétiseur et les fichiers WebAssembly nécessaires, sont incluses dans le package de l’extension.

Au premier usage, Neptune copie les ressources déjà contenues dans l’extension vers le stockage privé OPFS de Chrome et vérifie leur écriture avant la synthèse. Cette opération ne contacte aucun service vocal distant.

Le texte est transformé en audio dans un Web Worker de l’extension. Neptune n’envoie ni le texte à prononcer ni l’audio généré à un service distant de synthèse vocale. La voix Windows n’est pas utilisée dans le parcours normal de Neptune.

Intelligence locale

Neptune choisit automatiquement un profil local compatible avec les ressources déclarées par le navigateur. Lors de la première préparation, les poids du modèle WebLLM sont téléchargés depuis leur emplacement de distribution puis conservés dans le cache local IndexedDB de Chrome.

Lorsque l’intelligence intégrée de Chrome ou un modèle WebLLM local est utilisé, les instructions, le contexte utile de la page et les réponses sont traités sur l’ordinateur.

Hermes Agent optionnel

Lorsque l’utilisateur connecte Hermes Agent, les messages nécessaires à la réponse sont transmis directement au serveur Hermes configuré. Ce serveur peut être local à l’ordinateur ou auto-hébergé. Neptune n’envoie pas ces messages à un autre serveur Hermes.

Hermes peut utiliser sa mémoire, ses compétences et les outils activés dans sa propre configuration. Ces outils s’exécutent sur la machine ou le serveur qui héberge Hermes, et non dans l’onglet Chrome contrôlé par Neptune.

Pour les actions dans le navigateur local, Neptune privilégie son planificateur local. Si un repli vers Hermes est nécessaire, le contexte de page est envoyé dans une session de planification isolée avec instruction de ne pas utiliser les outils Hermes ni écrire en mémoire.

La clé API_SERVER_KEY est stockée chiffrée dans le profil Chrome. Les identifiants de continuité de session permettent à Hermes de retrouver le contexte associé à Neptune ; ils peuvent être renouvelés depuis les paramètres avancés.

Activation vocale

La permission microphone est demandée uniquement après une action explicite de l’utilisateur. Après autorisation, Neptune peut écouter les expressions « Neptune » et « OK Neptune » lorsque Chrome reste ouvert.

Si la permission est refusée ou fermée, l’accueil reste utilisable au clavier et propose de réessayer ultérieurement.

Autres fournisseurs externes

Lorsqu’un fournisseur cloud est choisi dans les paramètres avancés, les messages nécessaires à la réponse ou à la planification sont envoyés directement à ce fournisseur selon ses propres conditions. Neptune n’envoie jamais une clé API à un autre fournisseur que celui configuré.

Permissions navigateur

L’accès aux sites est demandé avant la première mission nécessitant de lire ou manipuler une page. Selon la décision de l’utilisateur, Neptune peut travailler dans la page actuelle, un nouvel onglet ou une nouvelle fenêtre.

Les permissions locales http://127.0.0.1/* et http://localhost/* servent uniquement à joindre un éventuel serveur Hermes local ou un autre moteur local explicitement configuré.

Actions sensibles

Neptune refuse d’automatiser les paiements, achats, suppressions de compte, mots de passe, codes secrets, signatures, virements et contournements de CAPTCHA. Les communications externes exigent une autorisation explicite limitée à l’action concernée.

Suppression des données

L’utilisateur peut effacer la conversation et le journal depuis les réglages. La commande « Nouvelle session » renouvelle l’identité de conversation Neptune–Hermes sans supprimer les mémoires déjà enregistrées par Hermes. Les données conservées par Hermes doivent être gérées depuis l’installation Hermes concernée.
