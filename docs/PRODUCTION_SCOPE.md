# Neptune — périmètre production

Neptune est livré comme une extension Chrome Manifest V3 autonome.

## Installation client

Le client installe uniquement l’extension Chrome. Aucun runtime Windows, serveur local ou jeton technique Neptune n’est requis.

## Fonctions livrées

- onboarding conversationnel au premier lancement ;
- prénom, voix, niveau de confiance et mot d’activation ;
- intelligence locale via l’API Prompt intégrée à Chrome lorsqu’elle est disponible ;
- intelligence cloud via Mammouth AI ou un endpoint OpenAI-compatible ;
- conversation textuelle et vocale dans le panneau latéral ;
- onglet de travail séparé pour chaque mission ;
- lecture, navigation, clics, saisie et envoi contrôlé ;
- validation obligatoire des actions externes ou sensibles ;
- arrêt immédiat, journal local et reprise après blocage ;
- stockage chiffré des clés fournisseur dans le profil Chrome.

## Limites assumées

- le mot d’activation fonctionne lorsque le panneau Neptune est ouvert ;
- l’extension ne contourne jamais les CAPTCHA, protections de plateforme ou restrictions de compte ;
- les paiements, suppressions, mots de passe, signatures et engagements contractuels ne sont jamais automatisés ;
- l’API Prompt locale dépend de la compatibilité matérielle et logicielle du poste.
